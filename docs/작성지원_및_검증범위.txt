작성 및 검증 범위

이 제출용 프로젝트는 준짱의 요청에 따라 자비스가 작성·검증을 지원한다.
기존 Ubuntu 기초 실습 파일·화면은 사용자 요청에 따라 이 제출자료에서 제외한다.
코디세이 첫 미션 원문의 조건을 기준으로 새 프로젝트와 새 검증 결과만 포함한다.
새 프로젝트 코드와 자동 검증은 지원 도구가 수행한 것으로 구분한다.
사용자가 직접 수행하지 않은 작업을 직접 실습했다고 기술하지 않는다.
예상 출력이나 의도적으로 만든 테스트 오류를 실제로 겪은 문제 해결 사례로 바꾸지 않는다.
GitHub 업로드·코디세이 평가 요청 여부는 실제 수행 후 별도로 기록한다.
