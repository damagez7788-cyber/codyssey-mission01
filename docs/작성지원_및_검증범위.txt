작성 및 검증 범위

제출자: 강준권

프로젝트: 강준권의 첫 개발 작업실 Jun Workshop

프로젝트 작성과 실행 검증에는 AI 도구를 활용했으며, 실제 실행 결과와 검증 기록을 함께 정리한다.
본 제출자료에는 미션 요구사항을 기준으로 구성한 프로젝트와 해당 검증 결과를 포함하며, 이전 기초 연습 자료는 포함하지 않는다.
코디세이 첫 미션 원문의 조건을 기준으로 새 프로젝트와 새 검증 결과만 포함한다.
프로젝트 코드 작성과 자동 검증 실행에 활용한 AI 도구의 지원 범위 및 실행 주체 표시는 원문 기록에 보존한다.
제출 문서는 제작 결과와 실제 검증 내용을 중심으로 설명한다.
예상 출력이나 의도적으로 만든 테스트 오류를 실제로 겪은 문제 해결 사례로 바꾸지 않는다.
GitHub 업로드·코디세이 평가 요청 여부는 실제 수행 후 별도로 기록한다.
